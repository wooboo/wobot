                                            Tutorial Introduction
This tutorial includes the following files to help you learn more about the car kit and programming knowledge:




"1_Get_start": This folder contains the robot assembly guide and necessary software environment files. In order to

complete the assembly accurately and quickly, please read and follow the manual in detail. At the same time, the premise

of realizing the program function is to correctly create the software environment. Please check the PDF files in this folder

first .

complete the burning of the smart car program and realize different functions!
